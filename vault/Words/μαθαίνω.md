# μαθαίνω

**I learn** · say it: mathéno · English cognates: mathematics

> Ο Τομ μαθαίνει.

## Pair it with

Build with your words: take one from each line and say it out loud.

- **Who:** μαθαίνω (I) · [[εσύ]] μαθαίνεις · [[αυτός]] μαθαίνει · [[εμείς]] μαθαίνουμε · [[εσείς]] μαθαίνετε · [[αυτοί]] μαθαίνουν
- **What:** [[ελληνικά]] (Greek) · λέξεις (words) · ένα τραγούδι (a song) · γραμματική (grammar) · [[καινούργιος|κάτι καινούργιο]] (something new) · να [[μαγειρεύω]] (to cook)
- **How, when, where:** [[γρήγορα]] (quickly) · [[σιγά]] (slowly) · [[πολύ]] (a lot) · [[κάθε|κάθε μέρα]] (every day) · [[μαζί]] (together) · [[καλά]] (well)
- **Use it with:** [[θέλω]] να μάθω (I want to learn) · προσπαθώ να μάθω (I try to learn) · αρχίζω να μαθαίνω (I begin to learn) · ελπίζω να μάθω (I hope to learn) · [[ξεκινάω]] να μαθαίνω (I start to learn) · συνεχίζω να μαθαίνω (I continue to learn) · αποφασίζω να μάθω (I decide to learn) · καταφέρνω να μάθω (I manage to learn) · σκοπεύω να μάθω (I intend to learn)
- **Try:** Μαθαίνω ελληνικά μαζί. (I learn Greek together.)

**Common in everyday Greek**
- **να μάθω** — Θα 'θελα να μάθω Γαλλικά. (I'd like to learn French.)
- **να μάθεις** — Είναι δύσκολο να μάθεις Γαλλικά; (Is it difficult to learn French?)
- **θέλει να μάθει** — Η Αιμιλία θέλει να μάθει Ελληνικά. (Emily wants to learn Greek.)
- **να μαθαίνω** — Μου αρέσει να μαθαίνω ξένες γλώσσες. (I like to study foreign languages.)
